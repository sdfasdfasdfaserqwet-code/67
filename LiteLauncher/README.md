# Lite Launcher

Лёгкий лаунчер: только иконки и папки, свайп вниз открывает шторку с быстрыми настройками.
Без размытия и стекла, чтобы не лагало.

## Что умеет
- Все приложения сразу на экране (сетка 4 колонки), без отдельного меню приложений.
- Папки: долгое нажатие на иконку, затем «В папку…». У папки можно переименовать или расформировать.
- Шторка (свайп вниз, когда список наверху): часы, дата, плитки: Интернет, Bluetooth, Фонарик, Звук, Авиарежим, Настройки.
  Фонарик включается прямо в плитке, остальные открывают системные панели
  (Android не даёт сторонним приложениям переключать Wi-Fi и Bluetooth напрямую).
- Долгое нажатие на «Интернет» открывает настройки Wi-Fi.

## Сборка

### Вариант 1: Android Studio
Откройте папку проекта, дождитесь Sync, затем Build > Build APK(s).

### Вариант 2: командная строка (нужны JDK 17 и Android SDK)
```
./gradlew assembleRelease
```
Если нет `gradlew`, используйте `gradle assembleRelease` (Gradle 8.7+).
APK: `app/build/outputs/apk/release/app-release.apk`

Release-сборка с R8 работает заметно плавнее debug. Подписана debug-ключом, поэтому ставится сразу.

### Вариант 3: без установки SDK, через GitHub Actions
Создайте свой репозиторий на GitHub, залейте туда содержимое проекта в ветку `main`.
Во вкладке Actions запустится сборка, готовый APK будет в Artifacts (`LiteLauncher-apk`).

## Установка на телефон через adb
Включите «Отладка по USB» на телефоне, подключите кабелем, затем:
```
adb install -r app-release.apk
```
Или, если лежит в папке сборки:
```
adb install -r app/build/outputs/apk/release/app-release.apk
```
Сделать лаунчером по умолчанию (можно и через настройки телефона: Приложения по умолчанию > Главный экран):
```
adb shell cmd package set-home-activity dev.lite.launcher/.MainActivity
```
Вернуть старый лаунчер: поставьте его в «Приложения по умолчанию» или
```
adb shell pm clear dev.lite.launcher
```
